\section{Engineering und Testing (Kap. 05)}
\label{sec:engineering-testing}

\subsection{Framework- und Implementierungsentscheidungen}

Statt eines Agentenframeworks wie LangGraph implementiert StudyMummy den festen
Workflow mit kleinen asynchronen Python-Klassen. Für drei lineare Rollen ist
dies nachvollziehbar: Kontrollfluss, Fehlerpfade und Toolrechte bleiben direkt
im Code sichtbar, zusätzliche Laufzeitabstraktion entfällt. Pydantic-Modelle
bilden Verträge für Kontext, Plan, Review und API-Antwort, FastAPI integriert
Authentifizierung und Dependency Injection, SQLAlchemy kapselt persistente
Zustände. Der Preis der Eigenimplementierung ist ebenfalls im Code sichtbar:
Checkpoints, Replanning, Zustandsgraph und Transaktionsgrenzen über mehrere
Agentenschritte müssen manuell gebaut werden.

Der OpenAI-kompatible Adapter isoliert Providerunterschiede, setzt Timeouts und
liefert deterministische Fallbacks für strukturelle Agentenaufrufe. Die Tool
Registry trennt JSON-Schema von Implementierung, die zusätzliche
\texttt{SAFE\_TOOL\_POLICY} folgt dem Least-Privilege-Prinzip. Trace-IDs im
Logging-Middleware und Phasenlaufzeiten unterstützen Beobachtbarkeit, wobei
kein externes Trace-Backend oder persistenter vollständiger Agentenlauf
implementiert ist. Angular und REST halten UI und Agentenlogik getrennt,
Docker Compose reproduziert PostgreSQL/pgvector, Backend und Frontend.

\subsection{Testfaelle und Beobachtungen}

den Optionen \texttt{-q -p no:cacheprovider} ausgeführt. Ergebnis: 37 Tests
bestanden in 10,68~s, beobachtet wurde eine
\texttt{StarletteDeprecation\allowbreak{}Warning}. Es erfolgte kein
Live-LLM-Aufruf.

Zwei zusätzliche Beobachtungen begrenzen die Aussagekraft. Das semantische
Experimentierskript des Backends brach vor einer Ergebnistabelle mit
\texttt{AttributeError} ab, weil der simulierte Tool Call kein Feld
\texttt{type} besitzt. Frontend-Tests wurden nicht ausgeführt: Angular verlangt
Node~22.22.3, 24.15.0 oder 26, verfügbar waren 24.11.0 und 24.14.0. Deshalb
werden weder Ergebnisse dieses Experiments noch Frontend-Erfolgszahlen
behauptet. Die bestandenen Tests decken vor allem Verträge und Fallbacks mit
Mocks ab, nicht fachliche Tutorqualität oder realen Mehrsitzungs-Lernerfolg.
