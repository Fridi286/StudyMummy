# StudyMummy

Welcome to the **StudyMummy** repository! 

To keep the repository clean and organized, the content has been divided into two main directories:

- 📂 **[`code/`](./code)**: Contains all the source code, tests, database migrations, environment configurations, and dependency files for the application. All development work and commands (like running the server or tests) should be executed from within this directory.
- 📂 **[`docs/`](./docs)**: Contains the project definition, exercise sheets, solution drafts, and other reference materials.

## Getting Started

To run the application or tests, please navigate into the `code/` directory first:

```bash
cd code
# then use your standard commands, e.g.
# uv sync
# pytest
```

For more detailed information on the project idea and architecture, check out [`docs/projekt_definition.md`](./docs/projekt_definition.md).
